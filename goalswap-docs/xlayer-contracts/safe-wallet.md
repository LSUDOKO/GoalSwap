# Safe Wallet on X Layer

> X Layer supports Safe (formerly Gnosis Safe) for multi-sig wallet management.

## Details

| Property | Value |
|----------|-------|
| Safe Version | Proxy Factory 1.3.0 |
| Verified | ✅ |
| App URL | [https://app.safe.global/welcome?chain=xlayer](https://app.safe.global/welcome?chain=xlayer) |

## For GoalSwap

Safe is useful for:
- **Multi-sig oracle wallet:** 2-of-3 signers for contract ownership changes
- **Protocol treasury:** Secure storage of collected fees
- **Emergency actions:** `pause()` and `unpause()` via multi-sig

## Contract Addresses

See [Safe docs](https://docs.safe.global/advanced/smart-account-supported-networks/v1.3.0) for Safe contract addresses on X Layer.
